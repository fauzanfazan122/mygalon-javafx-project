# MyGalon

Aplikasi desktop berbasis JavaFX untuk mengelola transaksi usaha depot air minum isi ulang. MyGalon membantu pencatatan transaksi, pemantauan pendapatan, pengelolaan harga, serta penyajian data dalam bentuk dashboard dan grafik sederhana.

## Fitur Aplikasi

* Dashboard ringkasan usaha
* Statistik transaksi harian
* Statistik pengantaran yang sedang diproses
* Grafik transaksi mingguan
* Manajemen transaksi galon
* Tambah transaksi
* Perbarui transaksi
* Hapus transaksi
* Pencarian transaksi berdasarkan nama pelanggan
* Filter dan pengurutan data transaksi
* Pengelolaan harga galon dan biaya pengantaran

## Teknologi

* Java
* JavaFX
* SQLite
* FXML
* CSS

## Struktur Modul

### Dashboard

Menampilkan ringkasan informasi usaha seperti:

* Total pendapatan
* Jumlah transaksi hari ini
* Jumlah pengantaran yang sedang diproses
* Grafik transaksi mingguan
* Daftar transaksi terbaru

### Transaksi

Mengelola seluruh data transaksi:

* Tambah data
* Edit data
* Hapus data
* Cari transaksi
* Filter dan pengurutan data

### Harga

Mengelola:

* Harga galon
* Biaya pengantaran
